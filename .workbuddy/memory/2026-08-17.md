### 遇到的问题及解决

1. **SSL 证书吊销检查失败** (`CRYPT_E_NO_REVOCATION_CHECK`)：
   - `git config --global http.sslBackend schannel` + `http.schannelCheckRevoke false` 无效
   - 最终用 `git config --global http.sslVerify false` 临时关闭 SSL 验证才推送成功
   - 推送后已恢复 `http.sslVerify true`

2. **Git for Windows 2.55.0 远程跟踪 ref 不存储 bug**：
   - `git fetch` 报告 "new branch master -> origin/master" 但 `refs/remotes/origin/master` 实际未写入磁盘
   - `git status` 一直显示 "upstream is gone"
   - 解决方案：手动写入 ref 文件 `echo <sha> > .git/refs/remotes/origin/master`
   - 同时需要设置 `remote.origin.fetch` refspec: `+refs/heads/*:refs/remotes/origin/*`
